A button that copies page content to the clipboard as Markdown.

== Description ==

Adds a "Copy to Markdown" button block. On click, it converts HTML from a configurable CSS selector (default `.entry-content`) to Markdown and copies it to the clipboard. After a successful copy, the icon switches to a checkmark and the label briefly shows "Copied".

== Installation ==

1. Run `npm install` and `npm run build` in this plugin directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Insert the **Copy to Markdown** block in the editor.
