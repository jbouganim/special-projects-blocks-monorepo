KB Docs block suite for docs layout composition in the block editor.

== Description ==

The KB Docs plugin provides four blocks:

* KB Docs (layout wrapper)
* KB Docs Sidebar
* KB Docs Breadcrumb
* KB Docs Content

Each block is single-instance and supports core color controls.
